2. Folder Structure (Where to find what)

Here is a breakdown of the most important folders and files in the app/ directory:

📂 `app/` (The Core)

  • data.ts: CRITICAL. This is where all the text for projects and skills lives. If you want to add a new project or skill, you edit this file!
  • layout.tsx: The main wrapper for the whole site. It contains the Navbar, Footer, and Google Fonts setup.
  • page.tsx: The homepage (Hero section, Stats, Projects, Skills).
  • globals.css: Global CSS variables (colors, dark mode setup).

📂 `app/components/` (Building Blocks)

These are reusable React components.

  • ApiConsole.tsx: The interactive API terminal in the Hero section.
  • Hero.tsx: The top section of the homepage with your photo and main headline.
  • ProjectCard.tsx: The clickable cards for your projects.
  • Footer.tsx: The bottom footer with links and contact info.

📂 `app/api/` (The Backend)

  • contact/route.ts: The secure server route that handles the contact form and sends emails via Brevo. Never expose your Brevo API key here. It is stored in Vercel.

📂 `public/` (Assets)

  • angella.jpg: Your profile picture.
  • Angella_Tendo_CV.pdf: Your downloadable CV.

3. How Everything Works Together

A. Routing (How pages load)

Next.js uses "File-based Routing". This means if you create a folder called contact inside app/ and put a page.tsx inside it, the URL /contact automatically works.

Dynamic routes (like /projects/vatra) use square brackets: app/projects/[slug]/page.tsx. The code inside reads the [slug] from the URL to find the matching project in data.ts.

B. Forms and Emails

When someone fills out the contact form, it sends a POST request to /api/contact. That route sanitizes the data, checks for spam (honeypot), and uses the Brevo API key (stored in Vercel's Environment Variables) to send you an email.

C. SEO & Metadata

SEO is handled in app/layout.tsx (the metadata object) and via auto-generated files like sitemap.ts and robots.ts. The opengraph-image.tsx file automatically generates the image you see when sharing the link on WhatsApp or LinkedIn.

4. How to Make Changes (The Workflow)

If you want to update the site, follow this exact workflow:

  1. Make the change: Open VS Code, edit the files (e.g., add a project to data.ts).
  2. Test Locally: Open your terminal and run npm run dev. Check http://localhost:3000 to see if it looks correct.
  3. Push to GitHub: Run these commands in your terminal: 
    git add .
git commit -m "Describe what you changed"
git push origin main
  4. Automatic Deployment: Vercel is connected to your GitHub repository. As soon as you push, Vercel will automatically rebuild and update the live website in ~60 seconds.
Important Rule: Never commit your .env.local file to GitHub! It contains your secret API keys. The .gitignore file prevents this, but always double-check.

5. Common Tasks

How do I update my phone number or WhatsApp link?

  1. For the footer: Open app/components/Footer.tsx and search for +256.
  2. For the floating WhatsApp button: Open app/components/FloatingButtons.tsx and look for whatsappNumber.

How do I add a new project?

  1. Open app/data.ts.
  2. Scroll to export const projects = [...].
  3. Copy an existing block and paste it at the top. Edit the slug (URL), title, description, and details.
